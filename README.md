# Pysearch
"A tiny search engine built from scratch."

A mini search engine built from scratch in Python — no frameworks, no external libraries.

Reads a folder of `.txt` documents, builds an inverted index (word → document map), and looks up any word in O(1) time.

**Reference:** *Grokking Algorithms* by Aditya Bhargava

## What It Does

1. Reads all `.txt` files from `docs/`
2. Cleans text — lowercase, strips punctuation
3. Builds `{word: [doc_ids]}` inverted index
4. Saves index to `output/index.json`
5. Looks up any word and returns the documents containing it

**Not included (yet):** ranking, stop words, multi-word queries, fuzzy matching.

## Functions

| Function | Input | Output |
|:---|:---|:---|
| `binary_search(list, target)` | Sorted list, target value | Index of target, or `None` |
| `load_documents(folder)` | Folder path | List of `{id, name, content}` dicts |
| `tokenize(text)` | Raw string | List of clean lowercase words |
| `build_index(documents)` | List of doc dicts | `{word: [doc_ids]}` dict |
| `save_index(index, path)` | Index dict, file path | Writes JSON file |
| `load_index(path)` | File path | Index dict |
